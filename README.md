#建议控制台记事本
这是我用Python开发的一个命令行记事本小项目。
## 功能
1.添加笔记
2.查看全部笔记
3.删除指定编号的笔记
4.自动持久化保存笔记：笔记存放在‘notes.json’文件，关闭程序后数据不会丢失。
## 运行方式
1.确保电脑已经安装Python环境
2.打开终端，进入项目文件夹
3.运行命令：
python notepad.py
## 文件说明
-‘notepad.py’：主程序代码
-‘notes.json’：自动生成，用来存放所有笔记数据
## 用到知识点
-json模块：数据持久化存储
-os模块：判断文件是否存在
-函数封装
-while循环实现菜单
-enumerate便利列表，同时获取索引和内容
-try-except异常捕获，防止非法输入让程序崩溃
-f-string字符串格式化
