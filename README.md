# 简易记事本（Python 控制台版）

一个基于 Python + JSON 实现的控制台简易记事本工具，支持笔记增删改查、持久化存储，多行笔记输入，关键词搜索，数据保存在本地 `notes.json` 文件。

## ✨功能特性

1. **添加笔记**：支持标题 + 多行内容输入，输入`#end`结束内容录入；自动记录创建时间、修改时间
2. **查看笔记**：所有笔记按**修改时间倒序**展示，内容自动截断预览，不显示完整大段文本
3. **删除笔记**：根据笔记 ID 删除指定笔记，做 ID 校验与非数字输入容错
4. **修改笔记**：通过 ID 定位笔记，更新标题与内容，自动刷新修改时间
5. **关键词搜索**：在标题、笔记内容中检索匹配关键词，输出匹配笔记列表
6. **持久化存储**：全部笔记保存到本地`notes.json`，程序关闭数据不会丢失
7. **异常容错**：json 文件损坏自动重置为空笔记库；非数字输入捕获异常防止程序崩溃
8. **预留导出函数**：内置单条笔记导出、全部笔记导出为 txt 文件函数（尚未接入菜单）

## 📂项目文件说明

```
.
├── main.py          # 记事本主程序代码
```

> 
> `notes.json`：程序首次运行自动创建；如果文件格式损坏，程序会自动清空，防止程序崩溃。

## 🚀运行环境

- Python 3.6+
- 依赖库：`json`、`os`、`datetime`，均为 Python 标准库，**无需额外 pip 安装第三方包**

## 📝运行方式

1. 将代码保存为 `main.py`
2. 终端 / CMD 进入项目所在文件夹
3. 执行命令：

```
python main.py
```

4. 根据控制台菜单提示输入数字选择功能。

## 📖使用操作说明

启动后菜单：

```
=====简易记事本=====
1.添加笔记
2.查看所有笔记
3.删除一条笔记
4.修改笔记
5.搜索笔记
6.退出
请输入你的选择（1-6）:
```

### 1 添加笔记

- 输入笔记标题回车
- 输入笔记内容，可以写多行
- 输入 `#end` 结束内容输入，可在输入文本最后一句的末尾添加`#end` ，也可在文本下一行添加`#end` ，保存笔记
> 
> 示例内容输入：

```
今天学习Python记事本
练习json持久化
#end
```
```
今天学习Python记事本
练习json持久化#end
```

### 2 查看所有笔记

笔记按照**修改时间从新到旧排序**，内容只预览前 80 字符，过长显示`...`。

### 3 删除一条笔记

输入笔记 ID 进行删除；输入非数字会提示错误，不会崩溃；ID 不存在会给出提示。

### 4 修改笔记

输入笔记 ID，填写新标题，新笔记内容，同样使用`#end`结束输入；自动更新修改时间。

### 5 搜索笔记

输入关键词，同时匹配**标题**和**笔记正文**，列出所有匹配笔记 ID、标题、创建时间。

### 6 退出

退出程序，笔记会提前自动保存。

## ⚠️注意事项

1. 不要手动编辑`notes.json`，格式错误会导致文件重置丢失笔记；
2. ID 逻辑：当前版本 ID 使用 `len(notes)+1`，删除笔记后 ID 不会自动重排；代码中写好了`get_new_id()`函数，当前添加笔记没有调用该函数，可以优化替换；
3. 内容里如果文本包含字符串`#end`会被识别为结束标记；如果需要文本出现 #end 字符，需要修改结束标记逻辑；
4. 所有文件编码统一使用 `utf‑8`，Windows 系统下中文不会乱码。
